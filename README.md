# pihta-channel-telegram

Тонкий Telegram-канал системы бронирования «Пихта». Ничего не знает про брони,
цены и базу: принимает сообщение или нажатие, спрашивает ядро
(`pihta-core`), рисует полученный экран.

## Переменные окружения

| Ключ | Значение |
|---|---|
| `BOT_TOKEN` | токен бота (вводится в панели, в код не попадает) |
| `CORE_URL` | `https://<домен ядра>` |
| `CORE_API_TOKEN` | общий секрет канала и ядра |
| `PORT` | необязателен: если задан, поднимается `/health` |
| `RELEASE` | метка релиза в логе |

## Что делает

- текст или `/start` → `POST /api/v1/text`;
- нажатие кнопки → `POST /api/v1/screen`;
- контакт (поделиться номером) → `POST /api/v1/contact`;
- ответ ядра → сообщение, фото-баннер, инлайн-кнопки; служебные
  подтверждения показываются плашкой (`callback.answer`), а не сообщением.

## Тесты

```bash
python -m unittest test_channel -v
```

Проверяют рендеринг, контракт с ядром (платформа, токен, тело запроса,
ошибки 400) и отрисовку экранов без сети Telegram.
